# 隐私

[返回 README](../README.md)

小队在本机处理数据，没有网络请求、遥测或模型调用。这里描述的是小队自身，不包括 Codex 应用的数据处理。

## 读取范围

读取本地任务的 ID、显示名称、项目路径、轮次状态和时间。SQLite 连接只读；不会修改 Codex 数据库或锁文件，也不会打开 `auth.json`。

为修正滞后的状态，读取器会扫描当前记录文件的字节，但只解析生命周期事件前缀。其余正文按块跳过，不解码或保留消息、推理和工具内容。不会读取可能包含完整首条提示词的旧 `title` 字段。

可选 Hooks 会在内存中解析传入的 JSON，仅保存 `session_id`、`turn_id`、`event` 和 `at`，不记录工具参数或返回审批决定。

## 本地保存

`~/.codex-workers/` 保存：

- `settings.json`：离场时间设置。
- `runtime.json`：进程、刷新时间、工人数量、窗口尺寸和错误信息，不含任务名、任务 ID 或正文。
- 可选的 Hook 事件元数据及写入锁。

工人名单只在内存中。窗口位置和大小使用 macOS 偏好设置；登录自启使用 `~/Library/LaunchAgents/local.codex.workers.login.plist`。点击「复制会话名」才会写入剪贴板。

调试时，读取器的终端输出可能包含任务名称、项目名和 ID，请勿直接公开。测试和仓库预览均使用虚构任务。

`CODEX_HOME` 和 `CODEX_WORKERS_DATA` 可分别指定数据源和小队数据目录；保持本地运行时，请使用本机目录。
